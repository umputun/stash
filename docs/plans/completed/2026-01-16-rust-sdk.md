# Rust SDK for Stash

## Overview

Add a Rust client library for the Stash key-value configuration service, following patterns from Go, Python, TypeScript, and Java SDKs. The Rust SDK provides:
- Idiomatic Rust API with options struct pattern (like Python/TypeScript)
- Strong typing with Result-based error handling
- Zero-knowledge (ZK) encryption support (optional feature)
- SSE subscriptions for real-time updates
- Full cross-SDK compatibility

## Context

**Location**: `lib/stash-rust/`

**Existing SDK patterns**:
- All SDKs use identical ZK encryption (AES-256-GCM + Argon2id)
- Common methods: `get`, `get_bytes`, `get_or_default`, `info`, `set`, `delete`, `list`, `ping`
- Subscription methods: `subscribe`, `subscribe_prefix`, `subscribe_all`
- Error types: NotFound, Unauthorized, Forbidden, Decryption, Connection, Response

**Dependencies**:
- `reqwest` (rustls-tls) - HTTP client
- `reqwest-eventsource` - SSE subscriptions
- `tokio` (rt-multi-thread, macros) - async runtime
- `serde`, `serde_json` - serialization
- `chrono` (serde) - timestamps
- `thiserror` - error definitions
- `argon2` - key derivation (optional, zk feature)
- `aes-gcm` - encryption (optional, zk feature)
- `zeroize` - secure memory clearing
- `base64`, `rand` - encoding/random

## Technical Details

### Client API

```rust
use stash::{Client, ClientOptions, Format, Error};
use std::time::Duration;

// simple creation
let client = Client::new("http://localhost:8080")?;

// with options
let client = Client::with_options("http://localhost:8080", ClientOptions {
    token: Some("my-token".into()),
    timeout: Some(Duration::from_secs(10)),
    zk_key: Some("my-secret-passphrase".into()),
    ..Default::default()
})?;

// KV operations
let value = client.get("app/config").await?;
client.set("app/config", "new-value", Some(Format::Yaml)).await?;
let keys = client.list(Some("app/")).await?;
client.delete("app/config").await?;

// subscriptions
use futures::StreamExt;
let mut stream = client.subscribe_prefix("app/").await?;
while let Some(event) = stream.next().await {
    let event = event?;
    println!("{}: {} at {}", event.action, event.key, event.timestamp);
}
```

### Error Handling

```rust
match client.get("missing").await {
    Ok(value) => println!("Got: {}", value),
    Err(Error::NotFound) => println!("Key not found"),
    Err(Error::Unauthorized) => println!("Invalid token"),
    Err(e) => println!("Error: {}", e),
}
```

### ZK Encryption (cross-SDK compatible)

Format: `$ZK$<base64(salt[16] || nonce[12] || ciphertext || tag[16])>`

Argon2id parameters (must match exactly):
- Time cost: 1
- Memory cost: 65536 (64 MB)
- Parallelism: 4
- Output length: 32 bytes

### Test Vectors (cross-SDK compatibility)

These values must produce identical results across all SDKs:
- Passphrase: `test-passphrase-16`
- Plaintext: `hello world`
- Verify: Rust can decrypt values encrypted by Go/Python/TypeScript SDKs
